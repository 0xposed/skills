# Shared skill-example context

When writing or revising examples across this skills repository, use a fictional interactive e-commerce application as the common setting. It has a product catalog, product details and quick views, filters, a cart with quantity controls, and a checkout flow.

Use only the parts of that scenario that help explain a skill. Keep examples illustrative: do not imply every app must use a particular framework, folder layout, API, design system, architecture, or business rule. The project being worked on always takes precedence over this fictional context.

This file is a maintenance reference for keeping examples coherent across machines; it does not add requirements to the skills' technical guidance.
